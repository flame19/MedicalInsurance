# Фронтенд реєстру медичного страхування

Vue 3, Vite, Vue Router, Axios і Bootstrap.

## Локальний запуск

1. Запустіть бекенд MedicalInsurance з PostgreSQL. Типова адреса API — http://localhost:8080/api.
2. У терміналі IntelliJ відкрийте каталог frontend. Для Vite 7 потрібні Node.js 20.19+ або 22.12+.
3. Якщо API має іншу адресу, створіть .env.local за зразком .env.example і задайте VITE_API_BASE_URL.
4. Виконайте npm ci, потім npm run dev.
5. Відкрийте http://localhost:5173. Сервер Spring Boot має дозволяти цей origin у конфігурації CORS.

## Перевірка CRUD

На сторінці «Договори» додайте клієнта та програму в секції «Довідники клієнтів і програм», якщо довідники порожні. Створіть договір, перевірте, що він з’явився у списку, змініть його статус і підтвердьте видалення. Команди npm run build і npm run preview збирають та запускають локальний перегляд збірки.

У разі розміщення збірки dist налаштуйте повернення index.html для клієнтських маршрутів /contracts та /about.
